# FlashCARD v2

Applicazione Android per la gestione di carte fedeltà e documenti personali.

## Funzioni

- Carte fedeltà
- Scanner Barcode
- Scanner QR Code
- Ricerca
- Categorie
- Ordinamento per utilizzo
- Cassaforte documenti
- PIN
- Biometria
- Funzionamento offline

## Stato

Progetto ricostruito partendo da sorgente pulito.
